## What every stub contains

Per `_DESIGN.md` §9, every file has:

1. **`//!` header** citing the C++ source path, line range, body LoC, v4 sub-unit id, parent.
2. **`## Mapping`** section naming the `_DESIGN.md` §1 row (or §2/§3 codec preservation) that applies.
3. **`## Out-of-scope methods`** section listing any §1 non-goals.
4. **Doc comments** on each method stating: inputs, outputs, errors (which `slatedb::ErrorKind`), invariants, original C++ source line.
5. **Method bodies** as `todo!("<hint>")` (in-scope) or `Err(slatedb::Error::invalid("non-goal: ...".into()))` (non-goals).
6. **No exposure of `THD`, `TABLE`, `Field`, `key_range`** — POD shapes (`TableShareView`, `KeyRangeRef`, `RowBytes`) used instead.
